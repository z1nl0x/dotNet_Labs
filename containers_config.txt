  Criar uma nova migration:
  dotnet ef migrations add NomeDaMigration --project AppExampleKafka.Infraestructure --startup-project AppExampleKafka.API

  Aplicar as migrations no banco:
  dotnet ef database update --project AppExampleKafka.Infraestructure --startup-project AppExampleKafka.API

  Comandos úteis complementares:
  # Remover a última migration (se ainda não aplicada)
  dotnet ef migrations remove --project AppExampleKafka.Infraestructure --startup-project AppExampleKafka.API

  # Listar todas as migrations
  dotnet ef migrations list --project AppExampleKafka.Infraestructure --startup-project AppExampleKafka.API


  # Dropar o banco inteiro
  dotnet ef database drop --force --project AppExampleKafka.Infraestructure --startup-project AppExampleKafka.API
